bevy-lua-rs-starter

A minimal ECS-direct Lua scripting integration for Bevy 0.18, on lua-rs. Every moving sprite is an entity whose tick is a Lua function looked up by name from a behaviors table. Source: github · Context: lua-rs#23.

wander (random walk, wraps) orbit (around the origin) bounce (off invisible walls) each behavior is a separate Lua function in behaviors.lua
